API Architecture

I built this project to demonstrate production-grade API design, JWT authentication, and Paystack integration. It is currently in Test Mode. Feel free to use test cards to subscribe and explore the live-scraped job data completely for free.

Test the API in Swagger UI
Core Endpoints
POST /auth/register Create a user account
POST /auth/login Generate JWT access token
GET /jobs Fetch paginated job listings
GET /jobs?location=Lagos Filter jobs by Nigerian city
POST /payments/subscribe Initialize Paystack test checkout
GET /payments/verify Unlock account via test payment
